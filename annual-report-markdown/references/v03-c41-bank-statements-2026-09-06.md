# V0.3-C4.1 银行业主表配置（2026-09-06）

## 目标与边界

C4.1 只解决已在招商银行 2025 年报中观察到的银行六类法定主表结构和关系问题。规则不使用公司名称、证券代码或页码特判。保险业主表、权益明细、扫描 OCR 及港股繁体/英文不在本阶段。

## 规则

1. **行业配置由科目证据触发**：使用“存放中央银行款项”“拆出资金”“贷款和垫款”“客户存款”等主表科目锚点。至少命中 3 个，或同时命中“净利息收入＋手续费及佣金收入”利润表键值对，才标记 `industry_profile=banking`。命中科目的单元格证据与配置一起保存。
2. **拆分日期表头**：MinerU 只提供有界的表区域。对“2025年/2024年”和“12月31日/12月31日”分成两行的表头，必须回到 PDF 原生词坐标合并期间证据，重建“项目/附注/当期/比较期”四列。MinerU 的 3–7 列候选本身不产生计算资格。
3. **所得税符号只选一种公式**：所得税单元格为括号负数时，执行“利润总额＋已带符号税额＝净利润”；为正数时，执行“利润总额－所得税费用＝净利润”。不使用绝对值，不同时试算两式后择优。验证结果记录 `formula_model` 和原始展示。
4. **银行科目别名**：增加“汇率变动…影响额”“现金及现金等价物净（减少）/增加额”“年初/年末现金及现金等价物余额”等有界同义标签，不改写原始科目。
