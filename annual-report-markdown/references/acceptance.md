# 验收基准：先有真实答案，再谈覆盖率（references/acceptance.md）

对应设计方案：§18 验收基准。

> 本文是**工程验收建议**，不是当前性能、承诺或已测结果。任何数字只有在代表性标注集上实测后才可引用。

## 1. 覆盖拆三个维度，分别报告

1. **内容留存覆盖**：正文、表、图、附注是否有记录、证据或明确未解析状态。
2. **结构恢复覆盖**：多少段落、表格、跨页关系及章节边界已可靠恢复。
3. **可计算数据覆盖**：多少财务值的文字、行列、期间、主体、单位及口径已确认。

例如：一张复杂表以原图保留且标为待复核，可以计入内容留存，不能计入已结构化或可计算覆盖。

## 2. 样本组织

### 选型集（建议 12 份起）

现有茅台、格力、中国铝业、中国平安半年报可作为起点；再加入繁体、英文、双语、非自然年与扫描/复杂页面。至少精标 120–180 页，含连续跨页片段；同时整份跑以检查目录与跨页行为。

### 首轮基准库（约 30–36 份）

主路线确定后建立，A/H 大致均衡，含完整年报与中期报告。按发行人及版式家族划分开发/调参/冻结测试集；**同公司相邻年份不能同时进入开发与测试**造成虚高。规模不足以支撑某类准确率结论时继续扩大对应样本，不根据目标倒推“已足够”。后续宣称大范围适用前，增加不同披露年份与未见版式的滚动回归。

| 维度 | 必须覆盖的样本 |
|---|---|
| 市场与语言 | A 股简体、港股繁体、港股英文、并排双语、独立中英版本 |
| 行业 | 非金融常见行业、银行、保险、证券、综合企业 |
| 期间 | 自然年、非 12 月年结、中期、季度当季与累计、非标准长度期间 |
| 口径 | 合并/公司、重述前后、准则差异、调整后指标、不同币种 |
| 表格 | 有线/无线、多级表头、横表、跨页表、横向拆表、中途更换表头 |
| PDF 质量 | 原生、扫描、混合、隐藏 OCR、乱码、旋转和裁切 |
| 其他内容 | 图表脚注、流程图、勾选框、页脚重启编号、双页扫描 |
| 版本 | 更正版、中英版本、A/H 对应文件、相邻年度口径变化 |

真实案例优先；可控合成样本用于稳定复现旋转、页序、低清、同页多节、金额符号等错误，不用合成结果冒充真实报告覆盖。

## 3. 人工基准内容

对选定页面标注：正文块及顺序、章节起点、表格区域、网格和合并关系、单元格原值、表头路径、单位期间主体、脚注关联、跨页关系、图表证据。

- 首轮至少覆盖 50–100 张代表性表格及足够多的关键财务单元格。
- 高风险样本由第二人或独立审核流程复查标注分歧。
- **单一模型自动生成的答案不能充当金标准。**

## 4. 分层指标与拟议验收门槛

| 指标 | 测量方式 | 拟议门槛或发布规则 |
|---|---|---|
| 页面登记 | 与 PDF 页清单核对 | 100%，每页有明确完成/失败状态 |
| 已检出对象去向 | 检查处理链及导出引用 | 100%，不允许无记录丢弃 |
| 关键表漏检 | 与人工标注区域对比 | 冻结测试集核心主表无已知漏表；其他表另报召回 |
| 原值与上下文 | 数字、符号、行名、列头、期间、主体、单位联合精确匹配 | 自动接受核心数据争取至少 99.9% 精确率；任何已知关键错配阻止发布 |
| 正文 | 字符错误率与段落/块顺序分别统计 | 冻结集不得重现整页倒序、整段消失、关键否定丢失 |
| 跨页拼接 | 与人工标注逻辑表核对 | 错拼关键表为发布阻断；保守不拼计入待复核率 |
| 证据回查 | 检查值及上下文字段能定位原 PDF | 所有自动接受核心数据 100% 有足够证据 |
| 人工复核负担 | 待复核对象/全部应处理对象 | 必须公开，不以大量拒绝掩盖精度不足 |
| 性能与成本 | 全书耗时、每页 P50/P95、峰值内存、调用费用 | 按本机和真实样本实测，不预报未经测试的秒数 |

要点：

- **99.9% 是目标，不是用几个示例就能证实的结论。** 必须报告样本数、拒绝/接受比例、各分层错误及统计不确定性。
- 同一表内许多格子并非独立样本，置信区间应考虑**报告/表格聚集**。
- 数据不足时写“观察到的结果”，不写总体准确率已达到目标。
- “覆盖大部分报告”应同时披露文档留存率、结构化率、可计算覆盖和复核率；不同语言、行业及扫描类型单独汇报，**不能用简单中文正文的高分冲淡港股复杂表格的错误**。

## 5. 首批固定回归用例

- 本地茅台第 2 页：一到十一的顺序正确，勾选和标题不散到页尾。
- 本地茅台第 5 页：主要会计数据和指标的期间、元/股、百分比、百分点不混淆。
- 本地茅台第 8 页：识别为正文加表格，所有金额和说明有去向，无双栏分支漏字。
- 本地茅台同页多节：第一、第二节及第七、第八节都能保留。
- 本地茅台“合计”：仍属于相应表格，页眉处理不误删。
- 跨页财务表：保留前页表头、续页数据和合并/公司边界。
- 港股同标题 continued：正确区分下一年度或另一计量口径的子表。
- 单位缺失、负数基期、空白/短横线：不补单位、不补零、不强制套同比公式。

任何回归用例如被已知能力之外的规则绕过（例如靠“识别失败即跳过”把问题页排除出测试集），该绕过本身构成发布阻断。

## 6. 已落地工具（V0.2 切片，2026-09-05）

| 工具 | 用途 | 与本节指标/门槛的关系 |
|---|---|---|
| `scripts/verify_tables.py` | 表体数值“文字层 + x 坐标”逐行核对 → `索引/table_verify.json/.md` + `目检/table_check.json` | 支撑“原值与上下文”指标的机器可重复近似；**不是**替代人工标注的金标准，也不覆盖单元格语义 |
| `scripts/build_eyeball.py` | 目检页（原页图 + 候选 + 核对 ✓/✗） | 人工复核负担可视化；`table_check` 直接给出“待核对/已核对”状态 |
| `scripts/run_tableslice.py`（已内置核对） | 切片完成即自动核对并汇总到 `quality.json` | 让“已检出对象去向/原值与上下文”可随每次运行复现 |

实测样例：平安 p14–15（7 表）7/7、移动 p126（1 表 16 行）16/16，经文字层核对一致。这仍是“切片级观察结果”，尚未达到本文件第 4 节对全书/多报告的门槛声明。

### 切片级观察结论（2026-09-05 · 定版）

**观察集**：17 个切片 = 5 份报告 × 三张主表（合并资产负债表/利润表/现金流量表首页）+ 平安 p14–15 + 移动 p126。
（平安/移动为部分人工标注样例；5 份报告主表页为自动切片，未人工标注。）

**文字层数值核对结果**：表 28/29、数据行 470/471 一致（`verify_tables` 文字层 + x 坐标法，见 quality.md §6）。

**为达成该结果累计修复的引擎/格式差异**（均已固化在 `verify_tables.py`，并尽量不做“反向改数”）：
1. MinerU 数字单元格逗号后带空格（`13, 788, 280, 669.65`）→ 数值键先剥离 空格/逗号/百分/括号/减号；
2. 标签全/半角标点差异 → 标签归一去标点；
3. 标签跨视觉行折行 / pdfplumber 在列边界切碎（`所有者权益（或股东权`）→ 整词= → 单行子串 → 跨 ≤4 行连读 → 词为标签前缀（≥5 字）；
4. 数值印在标签行之后的“纯标签行”上 → 数值行前视（取后 1–2 数字行）；
5. MinerU 把括号注“-”OCR 成“一/二”（`以“一”号填列`）→ 仅在“以…号填列”语境做减号归一。

**剩余 1 行（结构项，非数值错）**：长电 p087 空值结构行“（二）终止经营净利润…”，pdf 标签片段跨度过散、无数值。
属“按块重建行/跨行行名”（§9.3、§7.1 x 坐标列向重建）范畴，建议由 V0.2 结构层处理，不再用正则特判。

**边界（务必沿用）**：以上为**切片级观察**，不是覆盖率/准确率结论；只证明“单元格内容 vs 原页文字层”一致，
不代表期间/单位/主体/语义正确，亦未人工终核。engine 伪影（MinerU 把整段正文当表行，如伊利 p079）未被计入表内，应单独报告。
