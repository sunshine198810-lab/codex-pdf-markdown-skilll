# V0.3-B2.1 质量口径修正（2026-09-06）

## 目的

B2.1 不扩大解析对象，不改变 B2 已接受事实的证据门。它修复设计审计中发现的五类口径偏差，避免把“程序处理过”误报成“内容完整或可以引用”。港股、繁体和英文继续暂缓。

## 修正项

1. **身份**：标准包继续把文件名当候选，阅读入口不再声称已经用第 1 页完成交叉核验。
2. **内容留存**：没有图像侧人工标注时，`coverage.content_retention=null`。另报 `page_processing_rate` 与 `detected_object_accounting_rate`；二者都不能解释为可见对象召回。
3. **引用资格**：普通原生正文只自动计 readable/traceable。`citable` 与 `computable` 只计通过完整主表证据门的事实，并用 `unit_note` 说明统计单位。
4. **表格状态**：新增 `table_status`，分别报告 `detected_fragments`、`grids_extracted`、`rule_validated_fragments`、`computable_cells`。旧 `structured_tables` 保留兼容，但不能单独解释为结构已经验证。
5. **复核负担**：没有人工标注的“全部应处理对象”分母时，`coverage.review_rate=null`；新增 `review_burden`，按开放总数、高优先级、表格、图表和页面分别计数。
6. **整体状态**：不再因为报告中存在表格或图片就机械降级；仅在失败页、未解决页或开放复核项存在时为 `partial`。

## 不在本阶段解决

- 封面、重要提示、报表日期和版本关系的自动内容核验。
- 图像侧内容留存金标准和结构恢复/可计算覆盖率分母。
- 普通正文的完整句、限定条件和脚注核验，因此不自动授予 citable。
- 所有者权益变动表、复杂多级表头、重述多期间、附注表和行业专用报表。
- 扫描 OCR 独立证据链与矢量图表理解。
- 港股繁体/英文。

## 验收要求

- 既有茅台 409 条、格力 530 条事实和财务勾稽结果不得退化。
- 两个标准包的 `content_retention`、`review_rate` 均为 `null`，但页面处理率、对象去向率和分类复核数必须可见。
- 阅读入口不得出现“第 1 页内容已交叉登记”。
- 所有新增字段通过 Schema；单元测试与双样本 Schema 检查通过。
