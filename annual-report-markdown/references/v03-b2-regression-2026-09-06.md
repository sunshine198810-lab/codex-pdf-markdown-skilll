# V0.3-B2 自动无框线调度回归（2026-09-06）

## 目标与范围

B2 将 B1 的手动两步流程（先运行 MinerU，再传入 `content_list`）收敛为一条标准命令：

```bash
python3 scripts/run_parse.py run <report.pdf> --output <dir> --auto-borderless
```

按用户当前范围，本阶段不实施港股、繁体或英文支持。

## 调度规则

1. 先用 pdfplumber 扫描全书标题、物理页和已检出表几何。
2. 对每张中文法定主表，以下一主表、权益变动表或财务报表附注作为终止边界。
3. 范围内已有四列网格时不升级；仅有两列坍缩表或没有合格网格时才调度 MinerU。
4. 将所有目标页合并为一个连续切片，最多 32 页；超限拒绝扩大。
5. MinerU 只跑本机 `pipeline/txt`、中文、表格开启、公式关闭。运行日志、检测决策、`content_list` 和哈希均固化到研究包。
6. MinerU 不存在或运行失败时，标准解析继续生成保守候选包，失败原因进入 `run.json` 和 `open_issues`。
7. 自动模式与手动 `--mineru-content` 互斥，避免两套页码口径混用。
