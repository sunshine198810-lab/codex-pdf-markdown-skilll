# V0.3-C2 权益宽表原生坐标重建回归（2026-09-06）

## 目标

C1 能识别格力权益变动表，但 pdfplumber 物理网格把整页多行数据串入单个单元格。
C2 不再从该坍缩字符串反推，而是直接使用 PDF 原生 `page.words` 的 x/y 坐标：

1. 从多级表头词位置定位每个数值列中心；
2. 将竖排的“优/先/股”、“永/续/债”及拆分的“专项/储备”恢复为列标签；
3. 按 y 坐标形成视觉行，将“号填列）”、“存收益”等折行片段并回前一数据行；
4. 每个原生数值词必须唯一落入一个列槽；
5. 原生数值词数必须等于已归属数，重复落列、孤立数值或表头缺列均失败。

## 资格边界

- 重建结果只取代结构层的坍缩网格，原物理片段仍保留。
- 行标签、表头和数值均保存物理页与 bbox 证据。
- `accepted_scope=structure_only`、`eligible_for_calculation=false`、`facts_emitted=0` 不变。
- 未做权益变动勾稽、期末衔接、投入/分配语义或引用资格升级。
