# V0.3-C3 权益关键单元格事实回归（2026-09-06）

## 范围与放行规则

C3 不把整张所有者权益变动表升级为可计算表。仅检查每个明确列头下的三类法定汇总行：

- 二、本年/本期期初或年初余额；
- 三、本年/本期增减变动金额；
- 四、本年/本期期末或年末余额。

只有三值均为原文显式数值、逐格与原生 PDF 词坐标一致，并具备标题主体、期间、单位币种、会计准则、行标签和列头证据，且严格满足 `期初 + 增减 = 期末` 时，三个单元格才进入 facts。空白不推定为零；失配不反向改数；明细行保持不可计算。逻辑表本身仍为 `eligible_for_calculation=false` 和 `all_cells_eligible=false`。

## 防误用结论

- `accepted_scope=validated_key_cells_only` 只表示存在获准单元格，不代表整表可算。
- `calculation_validated_fragments` 继续只统计整片段规则验收的六类主表；另用 `fragments_with_computable_cells`、`equity_key_fact_fragments` 和 `equity_key_fact_cells` 报告权益局部放行。
- 关系成立只能证明这组三值内部相容，不能证明披露真实、单位必然正确或整列语义覆盖完整。
- 本轮只回归原生文字简体中文 A 股的茅台、格力样式；扫描、繁体、英文、银行保险专用表及权益明细行仍不在支持矩阵。
